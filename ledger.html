Why there's no auto-notification

iPhone doesn't let a plain website schedule its own notification for a fixed time every day — that only works for real apps, or for a website with a paid server constantly pushing at 9pm. Instead, use the free Shortcuts app already on your phone. It's more reliable than anything JavaScript could fake, and takes under a minute to set up.

Set up the 9pm reminder

  • 1Open the Shortcuts app on your iPhone.
  • 2Tap Automation at the bottom, then + in the top right.
  • 3Choose Time of Day, set it to 9:00 PM, repeat Daily, then tap Next.
  • 4Tap Add Action, search "Show Notification", add it, and type: "Log today's Apple Pay spending".
  • 5Add a second action: search "Open App" (or "Open URL") so tapping the notification jumps straight into Safari — open this Ledger page once first, then add it to your Home Screen (Share → Add to Home Screen) so it opens like an app.
  • 6Turn off "Ask Before Running" so it fires silently every night.

Add Ledger to your Home Screen

In Safari, tap the Share icon → Add to Home Screen. It'll sit on your phone like a real app and open full-screen, no browser bar. Your data is saved on this device only (nothing sent anywhere) — so use the same phone/browser each time.
